## 本轮设计决定

- 默认采用两个紧凑入口：Agent 图标与名称；模型名与供应商。交互设计保留合并入口作为比较方案。
- 刻度位于聊天内容左缘。悬停或键盘焦点显示问题与最后回复预览，单击直接平滑跳转，支持键盘选择。
- 用量入口位于输入框下方、上下文信息旁。显示当前连接的最紧张周期或余额；弹出查看周期、重置时间和所有平台。
- 发送与换行提示固定显示；设置返回统一使用顶部返回键。
- Claude 图标来自官方站点，Codex 图标来自已安装的官方客户端；出处见 `public/brands/README.md`。

## 最新调整：刻度高光与正在查看的轮次一致

实际操作 Codex 桌面客户端，核对滚动、预览与点击定位。SuperCode 原有实现只检查每轮是否经过视口顶部，导致最新轮次已进入画面，高光仍在上一轮。本轮按阅读位置计算当前轮次，滚到底部时识别短末轮；监听内容与视口尺寸变化，使用轮次 ID 保持历史加载时的对应关系。单击定位让问题平滑进入阅读区域，长历史重新排版时校正目标位置。前端 100 项、Rust 81 项测试通过；明暗主题、预览、定位、内容增长、窗口变化、新增轮次和历史加载均用实际组件验证。验证详情见 [对话刻度高光](conversation-index-highlight.md)。
