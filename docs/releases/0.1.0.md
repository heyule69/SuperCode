SuperCode 首个 Windows 版本。

- 统一使用 Codex、Claude Code、OpenCode 和 Pi，支持检测、安装、更新与连接测试。
- 流式聊天、图片输入、媒体预览、文件差异，以及消息排队和引导。
- 模型供应商、技能、插件、MCP，浏览器与电脑自动化。
- 透明 Logo 动画安装器，软件内自动检查 GitHub 更新、下载和重启安装。

下载 **SuperCode_0.1.0_x64-setup.exe**，选择安装目录即可。支持 Windows x64；使用 Agent 需登录自己的账号或配置 API。

从旧版更新时，请先从系统托盘退出 SuperCode。聊天和配置会保留。后续更新可在「设置 → 关于」完成。
