# 桌面窗口与系统托盘

点击窗口关闭按钮或 Alt+F4，默认隐藏到系统托盘，保留当前 WebView、对话、草稿、审批和正在运行的 Agent。普通最小化按钮保持 Windows 任务栏最小化行为。

托盘左键单击恢复主窗口；Windows 右键菜单使用跟随当前软件主题的弹出面板，提供：

- 最近对话：默认三条，标题与项目名左右排列，单击即可恢复对应工作区中的对话。运行中转圈，等待确认显示提示，完成未读显示蓝点；已归档和已移除内容不列出。
- 更多对话：展开有上限的滚动列表，超过三十条时提供搜索入口。
- 打开的窗口：多个工作区时可展开并单独恢复。
- 新对话：打开主窗口中新对话；已有任务运行时创建独立工作区，保留原任务。
- 新窗口：按需创建独立工作区，沿用当前外观，不替换主窗口的会话选择。
- 显示主窗口。
- 退出：关闭所有窗口，释放 Agent 及工具进程。仍有运行或等待确认的任务时，先询问用户是否退出并停止任务。

“文件”菜单提供相同的新窗口和退出入口。托盘创建失败时保留普通关闭行为，避免留下无法访问的后台窗口。外部 Agent 的审批仍传给用户，不由窗口管理自动批准。

主窗口隐藏前保存普通位置、尺寸与最大化状态；隐藏不冻结持久化，所以再次显示、缩放或最大化仍会更新记录。明确退出前通知所有 WebView 保存输入草稿，限时停止各 Agent，再将未结束的任务标为中止。Windows Job Object 随应用退出清理后代进程。

托盘面板宽度为 300 个逻辑像素，常规行高为 30 个逻辑像素，默认只列出三条最近对话。长标题省略显示，悬停可查看完整标题；更多对话展开后在列表内滚动。面板关闭原生窗口阴影，避免 Windows 首次展示时将隐藏标题栏高度计入尺寸、留下底部空白。

托盘面板使用独立的小型页面，不加载对话正文、设置页或启动 Agent。首次右键时才创建，不出现在任务栏；Escape 或焦点离开时收起，闲置三十秒销毁 WebView。定位考虑显示器工作区与缩放，边缘不越界。带版本号的展示请求防止已经关闭的菜单被延迟回调重新打开。非 Windows 平台保留系统原生菜单。

## 验证

`npm run build`、`npm test`、`cargo test --manifest-path src-tauri/Cargo.toml -j 1` 验证前端、协议、权限、窗口持久化和退出策略。

发布程序可用 `--desktop-smoke-test` 运行隔离的原生窗口测试，检查实际托盘创建、关闭隐藏、最大化恢复、隐藏后继续记录尺寸及独立窗口恢复，报告写入 `.supercode/desktop-smoke-report.json`。此测试的任务状态仅为数据夹具，不代表真实 Agent 运行，也不会自动批准请求。测试数据与 WebView 目录隔离，不改用户历史。

2026-10-08：156 项前端测试、135 项 Rust 测试通过。隔离的原生窗口测试通过，关闭后保留两个 WebView，恢复保留最大化，随后还原和缩放仍可更新记录，新窗口可独立隐藏与恢复，明确退出使测试进程结束。

## Windows 图标修正

仅替换 ICO 后，旧编译缓存可能让 EXE 仍带旧图标。`build.rs` 现在显式监听图标文件，修改时重新编译 Windows 资源。验证安装版时要比对 EXE 的全部 RT_ICON 资源与所选 ICO 帧，不能只检查软件内图片或安装文件大小。

2026-10-08：重新构建并安装 NSIS 包，安装退出码为 0。安装版与发布版 EXE 的 16、24、32、48、64、256 像素图标资源全部与源 ICO 一致。资源管理器仍缓存旧快捷方式图标时，将所选 ICO 以内容哈希命名保存到应用安装目录，并让本应用的桌面与开始菜单快捷方式引用它；刷新后实际显示橙色徽记。不删除系统全局缓存，也不重启资源管理器。
