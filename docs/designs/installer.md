# SuperCode 安装器 HTML 设计

当前预览为同目录的 `installer.html`，包含安装前、安装中和完成后三个阶段。界面只显示透明 Logo、安装目录、必要图标按钮和安装时的小百分比，不添加宣传文案、标题或步骤列表。

- 安装前：完整 Logo 轻微呼吸，目录可编辑，百分比隐藏。只有点击目录旁的下载图标或在目录框按 Enter，才进入安装演示。点击 Logo 或等待不会自动开始安装。
- 安装中：Logo 的 40 片沿弧线翻折、汇聚，中心显示百分比；目录锁定。主按钮可以暂停、继续演示。
- 完成后：完整 Logo 轻微定型，保持 100%，主按钮变为打开入口。HTML 中点击这个入口只派发 `supercode-launch-preview` 演示事件并显示勾选反馈，不启动真实软件。

右上角重置按钮可以随时返回安装前，以便重新查看整套流程。保留深色背景，不显示主题切换按钮；所有素材内嵌，图标没有白色底板。Logo 区域随窗口高度伸缩，安装目录始终完整显示，页面不显示滚动条。

渲染使用单一 Canvas 和预生成的 40 块透明纹理，每次只调度一个 JavaScript 动画帧。完成、暂停和页面隐藏时停止调度；设备像素比最多取 2；系统减少动画偏好会取消位移、翻转、粒子与呼吸动画。

`window.supercodeInstallerPreview` 提供 `start()`、`replay()`、`reset()`、`setProgress(0–100)`、`pause()`、`resume()` 和 `getState()`。状态包括 `phase`、播放状态与百分比。这些接口仅控制预览画面，不执行真实下载、安装或程序启动。

百分比和 Logo 使用同一进度值，尚未完成时不会通过四舍五入提前显示 100%。外部调用 `setProgress` 会进入相应安装阶段并停止演示计时，直到收到下一次更新。当前点击开始展示的是模拟进度；正式安装必须由安装过程的实际进度驱动，不能用固定时长代替。

用户已确认此设计。正式安装器源码位于 `installer/`，构建后输出到 `release/`；HTML 文件保留为可独立打开的设计演示。正式版移除了演示计时器，安装进度来自实际文件写入、备份、注册和校验，完成按钮实际启动所选目录中的 SuperCode。

正式界面将右上角的演示重置替换为关闭按钮，目录图标可打开系统文件夹选择器。安装期间锁定目录和关闭操作；错误时显示必要的错误提示并允许重试。详细构建、备份和验证说明见 `installer/README.md`。

预览检查覆盖默认停在安装前、主动开始、目录锁定、完成入口、重置、暂停继续、进度更新、减少动画、键盘操作与资源释放。此检查使用模拟绘图上下文，不代表实际浏览器视觉验证；正式安装器使用独立的 IPC 状态检查。
