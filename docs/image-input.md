# 图片输入

桌面版支持从输入框“＋ → 图片”选择多张本地图片，也支持复制图片或截图后，在消息输入框按 Ctrl+V。普通文字粘贴保持原有行为；“＋ → 文件”选到图片时也会自动按图片处理。

添加后显示缩略图，点击查看大图，右上角按钮可移除。可以只发送图片，也可以加上文字一起发送。图片随各个会话、项目和 Agent 的草稿分别保存；添加图片不会提前创建聊天记录。连续粘贴会依次处理，处理完成前暂停发送；途中切换会话，结果仍保存到原草稿。

支持 PNG、JPEG、GIF、WebP；单张最多 10 MB，每条消息图片合计最多 20 MB，图片、文件、目录和技能合计最多 12 个附件。损坏、空图片和超出限制的图片会提示错误。

图片经本地校验后保存到应用数据目录的 `attachments` 文件夹，用内容哈希去重。草稿和历史只记录路径、名称等元数据，不将图片 Base64 保存到 localStorage 或聊天数据库。原始文件之后移动或被清理，已导入的图片仍可发送、查看。缩略图在 Rust 中生成，解码限制内存与尺寸，任务串行执行并放在后台线程；聊天中只有接近视口的缩略图才加载，点击后才读取大图。

发送沿用各个引擎的原生图片输入：Codex 使用 `localImage`，Claude Code 使用 Anthropic 图片块，OpenCode 使用 ACP 图片块，Pi 使用 RPC 的 `images` 字段。发送的是原图，模型是否能识别取决于当前连接的视觉能力。

2026-10-08 验证：前端 130 项测试、Rust 123 项测试通过；覆盖剪贴板提取、格式和大小限制、附件去重、图片草稿序列化、导入后删除原文件仍可读取、缩略图及四个引擎的图片数据。桌面实测本地图片上传、画图复制后 Ctrl+V、大图预览、移除图片、切换会话保留草稿，以及关闭并重启应用后恢复图片草稿。真实 Claude Code + 当前配置的 Kimi K3 成功识别上传和粘贴的两张截图，测试会话已归档；截图位于 `.supercode/screenshots/image-input-native.png`。这些结果不代表每个模型或服务商都支持视觉输入。
