# 前端细节打磨

日期：2026-10-07。

## 本轮改动

- 会话：启动时恢复上次选中的会话和项目；初始化完成后再保存选择，避免覆盖旧记录。加载阶段显示状态，不闪现空项目。草稿和附件路径独立保存，最多保留 20 份草稿、每份 32000 个字符和 12 个附件。
- 输入区：命令列表支持方向键、Tab / Enter 补全和 Escape 关闭；输入法组合输入不触发发送。模型搜索框按 Enter 选择模型，不提交聊天表单。添加附件使用最新会话的附件集合，文件选择期间避免重复打开。
- 菜单：添加、模型、权限、上下文浮层互斥；点击外部或移出焦点时关闭，Escape 返回原控件。可用空间决定浮层方向、位置和高度。完全访问继续使用明确的启用确认；个性化设置复用同一个权限菜单。
- 对话：历史与执行过程不随每次输入重新渲染；消息加载和异步 Markdown 布局变化时继续跟随底部，向上滚动后保持用户位置。减少动画设置也影响“回到最新消息”。复制成功、失败与等待状态统一，卸载时清理计时器。
- 代码：代码、工具、日志和设置中的代码输入遵循所选字体；文件预览添加行号、指定行高亮和复制。每轮和工作区支持单文件 / 全部差异，删除文件可查看已有 Git diff。长代码与表格在自身区域滚动，保持页面宽度。
- 链接：项目文件链接在预览内定位，外部 HTTP / HTTPS / 邮件链接通过系统应用打开。前端和 Rust 均拒绝程序协议及嵌入凭据的 URL；本地文件继续接受项目边界校验。
- 设置：分类使用对应图标，大字号时导航保持单行；调整主题缩略图、表单焦点、空列表、错误位置及窄窗口操作栏。移除弹窗背景模糊，统一主题色，提升浅色 / 暖色次要文字对比度。
- 供应商：保存非当前连接、导入配置不会清空当前对话；当前版本中每个聊天独立绑定连接，切换前压缩上下文并保留原始历史。模型和连接筛选都有空状态；CC Switch 搜索后的全选明确标为“全选当前”。
- 用量：24 小时范围名称修正；按天统计单次汇总；账号额度查询独立显示忙碌状态，缺失百分比不显示为剩余 100%。
- 弹窗：背景控件不能获取焦点；初始焦点、Tab 限制与退出回焦统一。重命名和归档等待成功后再关闭，错误保留在当前弹窗。

## 长对话界面错位修复

- 复现用户反馈：隐藏的工具完成状态使用绝对定位，其静态位置越过对话滚动容器，导致外层 `.app` 滚动范围异常。旧路径使用 `scrollIntoView` 跟随回复时，外层也被滚动；验证场景中 `.app.scrollTop` 达到 539 px，顶部和侧栏消失，输入区上移，下面出现空白。
- 隐藏标签固定到所在定位区域的起点，避免其贡献远处的滚动范围。桌面根容器使用 `overflow:clip` 和受限网格行，防止外层被程序化滚动。
- 回复跟随和“回到最新消息”只滚动 `.chat-scroll`；命令方向键导航只调整命令列表自身的滚动位置。
- `.supercode/scroll-qa.html` 使用明确标识的 UI 场景复现十段长回复与完成工具记录，修复后追加回复和回到最新均保持外层 scrollTop=0。1280 × 720 与 760 × 580 的顶部位置为 0，输入区底部等于窗口高度，控制台无错误或警告。这不是新的真实 Agent 测试。
- `npm run build`、33 项前端测试、32 项 Rust 测试和 UTF-8 无 BOM 检查通过。
- 命令列表从第一项通过九次方向键导航到最后一项，选中项保持在列表内部可见，外层 scrollTop=0。没有执行命令或发送消息，验证后清空测试输入并关闭临时标签。
- 桌面发布版重新构建完成；在用户已完成的 Claude / Kimi 真实历史会话中检查长回复、工具详情展开与收起、返回最新消息，顶部和输入区均保持正常。没有中断用户正在执行的任务；等待其任务结束后更新应用。截图为 `.supercode/screenshots/scroll-layout-fixed.jpg`。

## 侧栏项目和聊天管理

- 项目行右侧提供“⋯”和新建聊天按钮，悬停或键盘聚焦时显示；新建聊天直接归属该项目，防止重复点击创建多个会话。
- 项目菜单支持置顶、编辑名称 / 目录、分区、资源管理器、VS Code / 系统终端、复制路径、批量归档聊天和移除项目。移除只隐藏项目，文件及聊天保留，重新添加原目录可找回。
- 聊天菜单支持重命名、置顶、已读 / 未读、移动项目、分区、分叉、分享、复制标题 / 内容 / ID、在新窗口打开、导出 Markdown、归档和永久删除。永久删除需在应用内再次确认；运行中的聊天禁止移动、分叉、归档或删除。
- 分区可创建、重命名、移除。项目和聊天都可分区，置顶独立展示，聊天只显示一次。删除分区后其内容回到默认位置。菜单具有键盘导航、子菜单、焦点恢复和视口边界定位。
- “已归档”支持搜索及恢复。侧栏状态保存到 SQLite，旧库增加独立表而不改写既有聊天和供应商配置，多窗口通过事件同步侧栏更新。
- 分叉复制完整的本地聊天记录，使用独立原生会话，首次继续时传入最近最多 100 条、64 KiB 的文字上下文。移动聊天或更换项目目录也使用此方式继续，原生执行状态与用量不会重复。分享提供本地 HTML / Markdown 导出；HTML 是无脚本的独立文件。
- `npm run build`、52 项前端测试、43 项 Rust 测试和 101 个文本文件 UTF-8 无 BOM 检查通过。独立 `.supercode/sidebar-qa.html` 验证重命名、置顶、移动、分区、未读、分叉、归档恢复和项目新建按钮，暗色菜单及 760 × 580 子菜单均未越界。此界面验证不运行 Agent。
- 本地 Claude、Codex 真实调用均通过分叉上下文、独立原生会话、原聊天不变、置顶和归档恢复验证，报告为 `.supercode/sidebar-claude-report.json` 与 `.supercode/sidebar-codex-report.json`。测试使用独立 SQLite 数据库并要求不使用工具。
- 置顶聊天优先纳入最近 500 条会话，避免旧聊天被数量上限挤掉；同名项目在移动 / 分叉菜单显示目录，避免选错。
- 桌面检查发现 Windows 同步 IPC 创建 WebView2 会导致新窗口空白，改为异步命令创建。依据 [Tauri 窗口 API](https://docs.rs/tauri/latest/tauri/webview/struct.WebviewWindowBuilder.html) 的 Windows 调用约束修复，并用实际发布版验证。

## 技能发现与斜杠菜单

- 技能扫描覆盖当前项目及上级目录的 `.agents/skills`、`.codex/skills`、`.claude/skills`，SuperCode 技能目录、本机技能目录、系统技能和已启用插件。支持自定义 `CODEX_HOME` / `CLAUDE_CONFIG_DIR`、目录链接和嵌套目录；不遍历技能内的脚本、引用和依赖目录。
- 同名且正文一致的技能合并来源；同名但内容不同的技能保留独立条目。设置列表增加技能数量和来源，详情展示路径与完整正文。非法编码或超限文件明确显示错误，不转换文件编码。

## 聊天独立供应商与模型交接

- 已添加或导入的连接绑定到聊天，默认连接只决定新聊天。切换聊天、打开独立窗口、重启、分叉时保留连接；删除已绑定的连接会提示先切换。更换密钥可直接保存，更换供应商端点或协议需添加新连接，以免悄悄改变旧聊天。
- Claude 子进程使用当前聊天的连接配置；Codex 按当前连接启动 app-server，并为原生线程指定供应商。原有全局单任务限制保留，多个聊天可以有不同连接，但同时只执行一个任务。
- 同一聊天切换模型或供应商，先由原模型生成交接摘要，再保存新连接、模型与摘要，下一次发送创建新的原生会话。摘要保留目标、约束、操作、验证、关键文件和待办；原始对话不删除。压缩失败或超时保持原连接，可重试。`/compact` 使用同样的压缩流程，保留当前模型。
- 摘要使用上次摘要、最初请求及近期记录，输入最多 160 KiB、200 条，输出最多 24 KiB；保留截断提示。摘要本身有用量，计入用量记录。摘要是有损内容，不能保证保留历史的每个字；原始历史仍可查看。
- 切换成功后，在旧回复结束与下一条用户消息之间显示一行灰色提示，例如“上下文已压缩 · Kimi Code → 智谱 GLM”。只在切换处显示一次，后续回复保持正文样式，输入框继续显示当前供应商与模型。
- 密钥已保存时显示固定长度的圆点，真实密钥不会返回前端。点击“更换”输入新 Key，取消或保存成功后恢复圆点；圆点不会进入保存参数。加载、连接和压缩状态与助手正文使用相同左边缘。
- 参考 [Claude 模型配置](https://code.claude.com/docs/en/model-config)、[OpenCode 模型选择](https://dev.opencode.ai/v2/docs/models/) 与 [OpenCode 压缩](https://dev.opencode.ai/v2/docs/compaction/)：同一会话可以更换模型，通常按上下文容量触发压缩，而非每次更换必压缩。SuperCode 按用户要求将切换做成显式摘要交接；这是本项目的产品选择。
- 本机 Codex 原生 `thread/start` / `thread/resume` 协议支持 `modelProvider`，自定义供应商需提供其支持的协议和凭据，见 [Codex 高级配置](https://learn.chatgpt.com/docs/config-file/config-advanced)。不改写本机全局供应商配置。
