# Codex 官方登录入口

2026-10-07。用户指出 Codex 分类同时显示“本机 CLI 配置”“OpenAI Official”“ChatGPT 官方账号”，并要求只保留当前官方登录。

重复来自三类路由：旧版本机 CLI 默认、CC Switch 导入的官方配置、本机官方账号入口。官方导入没有独立登录凭据，沿用本机登录，却被排序和模型选择当作单独的账号。

- Codex 列表只保留一个“ChatGPT 官方账号”，使用现有官方图标和本机登录控件。
- 排序迁移把旧本机入口与官方导入映射到此入口，在原来的排序位置去重；第一项继续决定新聊天默认，重开保持顺序。
- 保留独立的 API 连接，不按名称或图标删除连接。
- 历史对话仍绑定原路由，原模型、会话、导入配置均保留；模型选择统一显示官方账号名称，已选模型仍使用原会话连接。
- 额度页面只显示一个官方账号，隐藏同一登录的导入重复项。
- 不执行登录、退出登录或模型请求，不读取或输出账号密钥。

验证：前端 105 项、Rust 84 项测试通过；`npm run build` 通过。新增测试覆盖三入口合并、API 连接独立保留、顺序和默认迁移、历史连接保留、模型选择标记、旧会话输入框仍显示所选模型与官方图标，以及额度列表去重。

桌面发布构建通过，已生成程序与安装包并打开新版。真实数据的 Codex 顺序由 `[@local, codex:codex-official, @official]` 迁移为 `[@official]`，默认为官方账号，原有的一条导入配置仍保留。实际设置页显示“Codex 1”及唯一的“ChatGPT 官方账号”；额度列表显示 Kimi、智谱和一个官方账号。实拍为 `.supercode/screenshots/codex-single-official-login.png`，新版留在该设置页。153 个文本文件通过 UTF-8 无 BOM 检查。
