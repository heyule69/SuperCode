# 侧栏聊天运行状态与未读

侧栏行末在启动、运行及等待确认时显示灰色转圈，运行标记优先于之前保存的未读状态。完成但尚未查看显示蓝点，已查看不显示标记。需要审批时仍保留确认提示；正文中的“正在思考”继续使用文字样式。

Claude Code 与 Codex 共用持久化完成逻辑。任务成功完成或返回失败结果时，将终止状态和未读标记在同一个数据库事务中保存；主动停止本身不新增完成提醒。保留聊天置顶和所属分区。重复完成事件不重新标记已读聊天，旧轮次完成不结束新轮次。

已读回执要求该聊天位于前台且回复已加载，设置页、后台窗口和运行中的聊天不会自动清除未读。回执携带已加载消息的序号；数据库检查是否存在更新的结果，防止过期回执清除下一轮。点击聊天、返回聊天和重新聚焦窗口时重新判定。手动“标记为未读”不会被同一页面立即撤销。

验证：84 项前端测试、81 项 Rust 测试通过，包含运行状态优先级、重启保存未读/已读、旧轮次完成、过期回执、停止与失败行为。实际 React 组件与已读 Hook 使用隔离的浏览器测试数据验证了后台完成、点击查看、前台完成、设置页保留未读、手动标记和明暗主题；本轮未运行真实 Agent。截图位于 `.supercode/screenshots/sidebar-status-dark.jpg` 和 `sidebar-status-light.jpg`。
