## 来源与会话保存

- Markdown `![说明](<绝对路径>)` 可嵌入图片、视频或音频，也支持 HTTP / HTTPS 媒体地址。
- 普通 Markdown 媒体链接、反引号包裹的媒体文件路径会附加预览；只包含绝对媒体路径的代码块也可作为成果列表预览，其他代码示例不触发预览。同一引用不重复附加卡片。
- 本地相对路径以会话所属项目为根目录；绝对路径及本地 `file:` 地址可读取。拒绝网络共享和可执行 URL。
- Codex、Claude Code、OpenCode、Pi 的工具结果统一转换标准 MCP 图片 / 音频 / 视频、Claude base64 图片及资源块；截图显示在执行摘要下方，收起详情仍可查看。Claude / Pi / ACP 的媒体正文也可保留。
- 工具二进制写入软件数据目录下的 `media`，IPC、历史数据库仅保留小型引用，不把 base64 填进文字输出。工具返回的数据 URL 同样处理。元数据截断优先保留媒体引用。
- 旧版本已省略的图片二进制无法从数据库恢复；旧消息仍有有效文件链接或文件路径时，可直接生成预览。

所有 Agent 共用的客户端说明已明确这是图形聊天界面，要求通过真实媒体结果或文件引用展示，不再为了展示而复制到桌面或打开外部程序。

## 性能与播放边界

卡片进入视口附近才准备媒体。PNG / JPEG / WebP 在后台串行生成最长边 960 × 720 的预览，点击才请求原图；保留 GIF 动画，SVG 作为图片加载。单个本地图片及工具二进制上限 10 MB，单项工具结果媒体总量 20 MB、最多 12 项；原生 JSONL 事件仍遵守既有 4 MB 上限。

本地媒体使用 `supercode-media` 自定义协议，仅提供已登记的文件引用。视频 / 音频支持 Range，单次最多读取 1 MiB；HEAD 不读正文，大文件没有 Range 的请求不会整段读取。登记表最多 256 项。不会通过 IPC 读取整段录像，也不会因页面打开自动播放。

图片格式：PNG、JPEG、GIF、WebP、SVG、BMP。视频格式：MP4、WebM、M4V、MOV、MKV；音频格式：MP3、WAV、OGG、M4A、FLAC。能否播放取决于 WebView2 支持的实际编码；不支持或文件已删除时明确提示，可选择在系统中打开。远端媒体由浏览器直接请求，不通过后台下载或缓存。
