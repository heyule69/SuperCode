# Agent 图标来源

这些图标仅用于识别连接的 Agent，归原品牌所有。

- `claude.png`：Claude 官方站点 `https://claude.com` 声明的 favicon，资源地址 `https://assets.claude.com/95a868946ac8a31e5ff832e2899f294aa368b836.png?w=32&h=32`。
- `codex-light.png`、`codex-dark.png`：本机官方 Codex Windows 安装包 26.930.7945.0 的 `Square44x44Logo.targetsize-96_altform-lightunplated.png`、`Square44x44Logo.targetsize-96_altform-unplated.png`，按原样使用。

使用场景仅为 Claude Code / Codex 选择与状态，不作为 SuperCode 自身品牌。

## 平台图标

图标来自各平台官网或官方文档声明的 favicon，保存在本地用于识别连接。PNG 保留比例，SVG 使用官网文件；自定义连接使用名称首字，不根据模型名冒用品牌。
