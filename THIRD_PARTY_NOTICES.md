# File and folder icons

SuperCode uses the unmodified SVG icons and file associations from **Material Icon Theme 5.39.0**.

Source: https://github.com/material-extensions/vscode-material-icon-theme

The icon generator is a build dependency. SVGs are bundled locally; the app does not load icons from a CDN. The complete MIT license is included in the app's `file-icons/LICENSE.txt` assets.
